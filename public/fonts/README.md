# Police Waelek

La police est installée : `waelek.otf` (extraite du zip fourni).
nommé `waelek.ttf` (ou `Waelek.ttf`, `Waelek-Regular.ttf`, ou en `.otf` / `.woff2` / `.woff`).

Le jeu la charge automatiquement au démarrage (voir `src/font.js`) et retombe sur une police système si le fichier est absent.
